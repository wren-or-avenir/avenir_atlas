# 海洋背景重构：视觉分析与实现交接

> 2026-09-10。状态：已根据用户 05/06 录屏修正核心着色器，并进行 Chrome 实际渲染检查；最终审美验收仍由用户确认。本文的设计参数不是照片测量值。

## 1. 目标与边界

用户原始需求保留在 [ocean.md](ocean.md)。本文将需求、26 张指定参考图的视觉观察和当前代码检查转成实施决策；用户原文优先，本文替代旧文档中的海洋实现假设。day06 未被指定，不纳入参考。两张 current_look 只用于诊断，不是目标。

- 固定高处俯视，无地平线；海面铺满屏幕，上深下浅，无沙滩、无露出水面的陆地。参考图的岸线角度不等于目标构图。
- 白天：明亮而不刺眼的热带海水，深处浓蓝、浅处清透，可见水下礁石。白浪必须像破碎的水，不像金属高光或白色布纹。
- 夜间：大面积近黑水体，局部受扰动区域出现蓝眼泪；小浪细碎克制，大浪明显增强，不能把整张海面变成霓虹网。
- 日夜共用地形、波浪与破浪逻辑；发光不是另一套波形，也不是把白天泡沫整体染蓝。
- 普通小浪持续运动，间或有限范围的中、大浪；整体上→下推进。拒绝等距复制、全屏同步起伏和静止照片贴面。
- 海洋是内容下方的背景，不阻断菜单交互。先做好桌面；保留移动端/WebGL 不可用时的 CSS 降级。
- 本轮不做鼠标推浪、潮汐天文模型、完整流体求解、海浪音效、雨电新特效、菜单重构或新依赖。

主参考：白天 day07 的泡沫、day11 的中浪；夜间 night05 的小浪层次、night11 的大浪。其他图按指定局部补充，不对所有图片求平均。

## 3. 当前实现的根因

| 位置 | 已检查到的问题 | 重构决策 |
| --- | --- | --- |
| `ocean/shaders/ocean.frag.glsl` 水色 | 深浅色按 `vHeightN`（瞬时波高）混合，没有水深或海底 | 水色由固定水深主导；波面只改变折射、反射和局部透光 |
| `ocean/shaders/ocean.vert.glsl` 与片元梯度 | 波频率比例约 1.0812，尺度过近；高度做权重归一而梯度未对应归一；速度为 0 仍有时间项 | 一套共享波场和导数、分开的大小尺度；所有运动使用统一时钟 |
| 顶点位移/法线 | 正俯视正交平面仅移动 z，不改变平面轮廓；顶点斜率只从已关闭的 wake 获得，片元另算法线 | 不保留无效高细分网格来假装体积；用一致高度、法线与浪头形态表达当前视角 |
| 泡沫 | 主要按坡度触发、叠加时变 Voronoi，缺少破碎事件、年龄、输运 | 破浪源与残留泡沫分开；坡陡不自动等于白沫 |
| 海面照片纹理 | 生成脚本以整张 day09 制作灰度化细节，原图泡沫/光照不能被可靠分离；纹理漂移依赖基本为零的 `vNormal.xy` | 最终海面不再依赖这张照片乘色；程序地形不混入已有浪花 |
| 夜间发光 | 全局噪声项可以在没有破浪时发亮；日夜用不同泡沫阈值改变形态 | 发光从同一扰动源生成，有独立快速衰减；去掉全屏随机闪烁 |
| `colors.ts` / ShaderMaterial | 调色空间未统一，原始片元输出未显式完成输出色彩转换 | 在线性空间运算，最终只做一次输出转换；不靠不明 gamma 调参 |
| `webgl/mount.ts` | 强制白天；定时刷新只改 body 状态，没有同步海洋日夜参数 | 默认恢复真实时段；开发预览可强制，定时刷新同时更新场景 |
| `webgl/stage.ts` / 海洋资源 | 共享渲染器已有统一循环，但无场景级清理契约；几何、纹理、GUI 等清理不完整 | 只补海洋离屏更新与场景清理所需的最小钩子，保留一个 context/rAF |

路径均相对 `src/components/`。这不是继续微调现有 shader 的任务：缺少海底、破浪源和残留状态，颜色参数无法补齐这些结构。

## 4. 选定的实现方案

### 4.1 最小架构与能力边界

采用固定俯视的 2.5D 全屏水面：程序化水下地形 + 多尺度高度/法线 + 有限长度破浪前缘 + 一对泡沫历史纹理。复用 Three.js、现有 Stage、主题与气候接口，不引入 FFT 海洋库、物理引擎、全局后处理框架或第二画布。

先用单个全屏平面替换 256×256 顶点网格。俯视下的体积来自局部浪面、反射遮蔽、卷气与厚薄泡沫，不来自无效的 z 位移。此方案不能表现真实翻卷的多层几何和飞散水滴；这是明确上限，不保证仅凭平面 shader 达到所有照片的真实感。只有完成下文分阶段验收后仍明确缺少可见翻卷体积，才升级局部浪头几何；不要提前做完整海洋模拟。实现处用 `ponytail:` 注释说明此上限。

### 4.2 坐标、海底与清透水体

- 统一水面坐标：`uv.y=0` 为画面底部浅水，`uv.y=1` 为顶部深水；世界 y 向上，主传播方向为负 y。x 按视口宽高比校正，圆形细节不随窗口拉伸。
- 初始可见纵向尺度设为 40 个世界单位，按米解释仅用于调参；不是从照片测出的尺度。缩放窗口不重新随机生成海底。
- 水深是静态函数：底部约 0.5–2，顶部约 10–14，平滑过渡并叠加低频地形变化。礁石集中在下部约 1/3，形状、大小、间距不均匀，始终完全没入水下。
- 同一海底高度场同时决定水深、石群轮廓及浅水破浪倾向，避免“画出来的礁石”和波浪避让位置不一致。优先直接在 shader 用少量固定种子的地形函数，不建立通用地形系统。
- 海底底色使用低对比灰褐/橄榄色，缝隙偏暗；表面法线造成小幅动态折射。深水吸收遮住海底，不是将岩石本身随时间变色或移动。
- 用按通道的 `T = exp(-absorption * depth)` 近似水下光路衰减；底色透射与水体散射混合，再与表面反射组合。反射使用视角/法线相关 Fresnel 与柔和天空色，不用整片白高光覆盖水下内容。
- 太阳接近头顶但略偏一侧，避免全屏镜面反射；微波产生稀疏短小闪光，与白沫分开。先关闭焦散也应清透；基础通过后才加很弱的浅水焦散，不另开物理求解。

### 4.3 波场与破浪源

波场要区分大尺度起伏、有限浪组和细碎表面法线。少量方向性波可以表达基底，但不能单靠叠更多正弦获得破浪。高度和导数共享 GLSL 源，注入水面与历史更新材质；用本地字符串片段即可，不建立全局 shader 注册系统。

- 基底约 6–8 个分离尺度的波，主方向上下、少量斜向交叉；大起伏主导高度，短波主要贡献法线。权重归一对高度及导数一致，数值差分检查导数。
- 有限浪组由 CPU 固定种子的简单调度器生成，固定最多 8 个活跃槽位。每组有出生时刻、速度、横向中心/长度、弯曲形态、强度，整体从画面上方进入并从下方退出。局部破浪不必横跨屏幕。
- 初始节奏：普通浪组间隔约 4–7 秒，传播约 3–5 单位/秒；每 20–40 秒一组更明显的中/大浪。全部是可调导演参数；先看运动再校准，不声称由图片推算。满槽时跳过新生成，不覆盖仍可见的事件。
- 前缘可由 `q = worldY - frontY(worldX, time)` 定义；向下行进时 `q>0` 为后方。横向包络控制有限长度，固定在浪组坐标内的低频扰动形成凹凸和分段，而不是每帧重新随机。
- 破浪源必须同时满足“在活跃前缘附近”“局部足够陡/浪高相对水深足够大”“横向包络有效”；朝向和高度用于区分前缘与背坡。浅礁附近更易破碎，也允许强浪组在深水局部破碎，满足 day13。
- 初版用平滑地形函数调制前缘形状和局部强度，表达绕礁、分叉、不同步破碎；这是视觉近似，不宣称求解浅水波折射。不要直接使用 `speed(depth) * time`，长期积累会把前缘撕裂。
- 中/大浪同时改变前缘宽度、卷气面积、破碎分支尺度和残沫量；保持大小浪共存，不把全屏波幅同步呼吸。与气候联动有界限，不能暴雨时直接把全屏染白。

### 4.4 泡沫与蓝眼泪的历史

这是本轮唯一新增的必要持久渲染状态：两个互换读写的 RenderTarget，保存过去的破浪，而不是让泡沫永远紧贴当前坡度。

- 历史图以最多半个 device-pixel-ratio 的分辨率起步，长边上限 1024、保持比例。使用 RGBA8、线性过滤、ClampToEdge、NoColorSpace，无深度/模板/mipmap。R=残留泡沫，G=发光受激程度，B=卷气浑白水体，A 不承载额外系统。
- 固定步长 1/30 秒，每显示帧最多推进 3 步；恢复后台页面时丢弃过量积压。场景使用同一模拟时钟，不把真实墙钟跳跃注入波浪。暂停时波场和历史都停止。
- 每步先从旧纹理沿流速反向采样，再衰减，最后注入本步破浪源：`state = clamp(advected * exp(-dt/tau) - quantizationDrain + source * dt, 0, 1)`。离开 UV 边界的旧状态视为零，不能靠 Clamp 将边缘拖出永久长线。
- RGBA8 小值衰减可能量化停滞；每步设置至少 `1/255` 的衰减排空量并对极小值归零，验收时检查“停止注入后确实消失”。这是低精度方案的有意折中，不能忽略。
- 初始时间常数：泡沫约 3–5 秒、发光约 0.6–1.4 秒、卷气约 1.5–3 秒。历史流速小于浪峰传播速度，形成前缘前进、残沫留后并缓慢漂移的区别；勿将尾迹与浪头锁死。
- 新浪头的窄高分辨率破浪源可直接加入最终着色，保证细亮边不被半分辨率抹掉；历史负责较宽的残留。高频纹理在随水移动的坐标内调制密度，不能只在屏幕上闪烁。
- 泡沫表现至少三层：厚的团簇浪头、薄的分支残网、稀疏的微泡；孔洞尺度不一、边缘破碎、内部有轻微蓝灰厚度阴影。细节噪声仅修饰形态，不替代形态。
- 夜间沿用同一破浪源，源强随局部扰动增大；G 衰减比 R 快，因此旧白沫可以仍在而蓝光已经淡去。无扰动处不能凭噪声持续发光。
- 夜色由近黑水体 + 受激蓝光组成：小范围青白亮核、青色颗粒、外围较暗钴蓝辉光。先从 G 的少量邻域采样做局部柔光；不加全局 bloom 影响金色地球与后续 UI。

### 4.5 色彩初值与背景关系

以下是肉眼归纳的 sRGB 调色起点，**不是取色器采样值，也不是必须锁死的验收数值**：

| 层 | 起点 |
| --- | --- |
| 白天深水 | `#06384F` / `#07415B` |
| 中间水体、浅水 | `#087F9C` → `#14A6A4`；底色、吸收和反射共同决定结果 |
| 礁石 | `#635A3D` / `#263E36`，低对比，不像漂浮迷彩 |
| 日间厚白沫 | `#EAF4F1`，薄处透出水色，避免无层次纯白 |
| 夜间基底 | `#020813` / `#031329` |
| 发光暗缘、主体、极亮核 | `#084BCD` → `#03BDEB` → `#B5F7FF` |

颜色输入经明确的 sRGB→Linear-sRGB 转换，在 shader 内做光照和混合，最后用 Three.js 输出色彩 chunk 转换一次。数据纹理保持 NoColorSpace。不要同时手写 gamma 和套输出转换；不要全局更改 renderer 色调映射/曝光而意外改变地球。

不提前给整张海面加黑遮罩来迁就尚未实现的菜单；需要时由内容容器提供局部可读性衬底。背景 canvas 不接收指针，放在内容下面但不落到 body 背景后面。CSS 降级也遵循上深下浅、无沙滩。

## 6. 分阶段实施与停止条件

每阶段只推进到其验收点。先建立可观察的结构，再调参数；禁止用新噪声层掩盖结构缺失。

当前代码进度：共享 `field.glsl` 统一地形、波场和曲线破浪源，替换水平软光条；泡沫使用全分辨率细节与低分辨率残留密度组合，破浪源只在窄前缘注入，夜间独立退光。水面法线使用一致导数，加入水下折射、礁石细节与吸收，移除旧噪声的精度伪影和反向 smoothstep。Stage 在地球叠加前清除深度，并恢复离屏绘制状态。

开发预览：`/?ocean=day`、`/?ocean=night`，无参数保持自动昼夜。面板可切日夜、暂停、重置及水深/法线/破浪/历史视图。浏览器检查入口为 `node scripts/check-ocean-browser.mjs day <截图路径.png> 8 motion`（先启动后台 Astro 和独立 Chrome 调试端口 9223）；night 同理。固定 seed 的重置会同时清空历史和模拟时钟。

验证记录：66 项单测、TypeScript、Astro 构建通过；单测需在沙箱外运行，沙箱内 Node 用户信息查询返回 ENOMEM。Chrome 已实际编译日夜 shader，检查连续模拟截图及暂停/重置。画面中的曲线破浪、残留孔洞、深浅层次已有明显改善；仍是程序化俯视近似，不将其宣称为照片级复刻，未给出未经测量的 60fps 保证。

1. **可复现基线与水体**：开发预览支持日/夜、固定 seed、暂停/恢复/重置；先做静止海底、水深、统一波场和颜色空间，不开泡沫。验收：下部岩石固定且可辨，上部被水体遮住；折射随水面变化，颜色不随波峰整片跳变；没有布褶般等距明暗带。
2. **破浪与历史**：加入有限浪组、厚前缘、残留与卷气；调试视图至少可切水深、法线、破浪源、泡沫历史。验收：能逐帧解释一次“形成→前进→留下残沫→消散”；浅礁破浪与地形对应；深处能出现局部孤立白浪；中/大浪改变形态而非只变白。
3. **夜间蓝眼泪**：复用同一模拟，在受激历史上着色与柔光。验收：切日夜不改变浪的位置/破碎时机；小浪对照 night05，大浪对照 night11；亮核有结构，旧浪更暗，无源处不自行满屏闪烁。
4. **集成与回归**：主题更新、气候范围、resize、dispose、降级、内容层级；再检查地球和其他场景。不要把新增天气或交互混入本阶段。

固定 seed 的截图不能只把时钟设到 30 秒：有历史的状态必须从清零按相同步长重放到目标时刻。预览重置必须同时重置调度、模拟时钟和历史图。

### 验收证据

- 日/夜各给平缓、普通破浪、大浪三种同 seed 截图，建议 1920×1080，并检查一个较窄桌面尺寸。对比图不带调试面板；另保留必要调试视图排查成因。
- 录制至少 40 秒日间与夜间运动；若设定的大浪未落入此窗口，延长到能覆盖一次大浪完整生命周期。检查方向、节奏、泡沫残留及光衰减，不能用单张截图证明自然运动。
- 高优先级否决项：沙滩/地平线、漂浮礁石、全屏等距布纹、没有孔洞与厚薄的白高光带、泡沫紧贴浪峰瞬灭、均匀霓虹线、全屏随机星点、夜间底色过亮。
- 照片级真实感由用户或具备读图能力的模型审核。不能读图的实现模型应提交截图/视频并标记“待视觉验收”，不得因测试通过宣称复刻成功。
- 运行 `npm test`、`npm run typecheck`、`npm run build`；其中 GLSL 必须另在实际浏览器编译运行，TypeScript/build 成功不等于 shader 正确。用仓库约定的后台方式启动服务。
- 最小自动检查覆盖固定 seed 可复现、事件槽位/范围、统一暂停时钟、日夜不改破浪物理参数。历史排空、shader 输出色彩与离屏状态恢复用实际浏览器检查；如现有测试条件支持再自动化，不新建庞大测试设施。
- 桌面 1080p 下以接近 60fps 为调优目标，记录实际 GPU、DPR、浏览器及帧耗时，不作未经测试的性能保证。先限制历史分辨率/细节采样，再按实测降低 DPR；不要默认堆叠高倍像素与后处理。
