## 遇到的问题

- development_bible.md 的 app/ 分层与四级错误分类在 Astro 语境下冗余 → 已加注解决
- contour 粗轮廓为占位数据，真实地图轮廓待 menu 模块 SVG 路径落地后回填
- tsc 缺 @types/node → 已补装
- 朔望月整数倍时浮点误差让相位≈1 导致月相名误判为残月 → 代码内归一化（>1-1e-9 归零）
- 浪花初版不可见：泡沫阈值与浪高不匹配、光照对比不足 → 重写着色器（多层涌浪、泡沫散斑、高光）
- 初版海面像"海底"（四向交叉浪像沙丘、散点泡沫像沙子、大片柔光像水下光柱）
  → 用户提供 27 张参考图（docs/design/reference/ocean/），以 day_07（白天青绿）、night_12（蓝眼泪荧光）为基准二次重构；
  参考图颜色数据用脚本采样提取（模型无法读图）
- 像素方块、圆形涟漪、四向交叉浪不符合真实海面 → 以 night_11 为标杆三次重构：
  涌浪改 45° 斜向 + 相位噪声去规律感；浪花改浪脊线连续细条；浮游闪点改圆形软边；
  鼠标交互改为"风推波"（轨迹波前垂直行进方向、向前推进、随时间消散，浪尖自动浪花/荧光）
- 后台 dev server 文件监听器失效，持续提供旧文件导致"刷新无效" → 重启后恢复，后续改着色器后需验证 HTTP 内容再让用户强刷

  顶点着色器循环索引 uniform 数组（ES 1.00 禁止）、变量名 patch 撞 GLSL 保留字、
  格点噪声硬跳变导致几何块 → 全部修复，浮层诊断常态化
