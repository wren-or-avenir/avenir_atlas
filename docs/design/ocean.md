  ## 8.当前我觉得比较假的地方（第二轮）
  day和night都有的地方：在night里面我会比较容易通过浪的颜色和形状来来判断浪的大小，也会更直观的看到浪速。在真实世界的流体力学中，海浪的波高、波速、泡沫以及消散过程，本质上是一个能量传递与释放的完整链条。深水区： 浪速主要取决于波长而非波高。但在现实中，由强风卷起的巨浪通常伴随着更长的波长，因此越大的浪往往跑得越快。近岸浅水区： 当浪靠近海岸时，水深变浅，底部摩擦力增加，浪速转由水深决定（水越浅，浪越慢）。由于前方的浪速减慢，后方的水流不断涌上，导致波长缩短、波高急剧增加，浪变得越来越陡峭。泡沫是海浪“崩溃”的直接产物。当浪峰变得太陡峭（通常波高与波长之比超过 1:7，或水深小于波高的 1.3 倍时），浪顶的水流速度会超过波浪本身的推进速度。空气卷入： 失去支撑的浪峰会向前倾倒、破碎，将大量空气卷入水中，形成密集的微小气泡，这就是我们看到的白色泡沫。能量标志： 泡沫越多、越浓密，说明破碎时的相对速度越大，波浪蕴含的初始动能也就越强。
  1. 泡沫的出现无视了水深（违背破碎临界点）
  深水区和浅水区，竟然出现了形态和粗细完全一样的碎浪白线。
  2. 泡沫缺乏“消散”的拖尾过程（违背能量衰减）
  图中的白浪像是一根根用画笔画上去的细线，只有前面，没有后面。
  波浪破碎产生泡沫后，泡沫不会瞬间消失。真实的碎浪向前推进时，波峰处是浓密的白沫，而波峰后方会拖拽着一片正在逐渐消散、变薄、成网状的泡沫轨迹（Spume/Foam trailing）。这张图里的泡沫没有“从浓烈到消散”的生命周期，显得非常僵硬。
  3. 波浪缺乏体积感与速度差（缺乏 3D 形变）
  即使是俯视角，波浪看起来也完全是扁平的，白线只是附着在基础水面纹理上。
  我们说过，浪变大是因为速度骤降导致海水向上挤压。这意味着波浪前方（迎浪面）应该非常陡峭，甚至产生自阴影；而后方（背浪面）则相对平缓。这图里的水面法线（Normals）或顶点位移（Displacement）没有表现出这种不对称的挤压感，导致水墙没“立”起来。
  4. 波长没有随水深发生变化（违背浪速规律）
  海浪从深水走向浅水时，浪速变慢，后面的浪会“追”上前面的浪，导致波长变短，浪与浪之间的间距会越来越密。

  ## 10.当前我觉得比较假的地方（第三轮）
# 深水区的网格状噪点
  画面上方（深蓝色区域）出现了均匀的、类似瓷砖平铺的白色噪波点。真实的深海哪怕有白沫，也是随风散布的簇状，绝不会是这种规则移动的网格贴图，这看起来像单纯的 UV 动画。我不知道你是想表达是反光还是白沫。
# 泡沫缺乏衰减拖尾泡沫缺乏衰减拖尾。
  浪花出现和消失的方式太过生硬。真实的碎浪在波峰处最浓，波峰扫过之后，会在后方海面留下大片逐渐变薄、呈网状消散的泡沫拖尾，而图中的泡沫只有前面，没有后面。我看有时候居然有一大片网状泡沫从深海飘来，这个很假。
# 波浪立体感
好像有了点立体感，但是深海过来的浪居然有时候一点浪花都没有，空有一个浪，波峰一起像固体一样往前滑，浪花它没有“波峰翻卷砸下”的动作。
