# 暂定设计
背景：俯瞰动态的一片海洋，收引力与潮汐影响海浪大小
鼠标动态：鼠标动到哪，海浪动到哪
网页加载图标：春：蘑菇。夏：海浪。秋：落叶。冬：雪
极端气候与真实映射：台风与暴雨： 页面增加斜向的动态雨丝图层，整体色彩饱和度降低。给鼠标的移动轨迹刻意增加一点“阻尼感”，模拟狂风中前行的物理错觉。
经纬菜单与 3D 地球联动：将导航菜单重构为真实坐标。例如，将“个人知识库”的菜单项设定为旧金山的经纬度。当鼠标悬浮在该坐标上时，角落的 3D 地球自动自转并平滑聚焦到北美板块，在地图上打下一道光柱。
阅读进度指示器： 将右侧的滚动条替换为月相变化。文章开头是满月，随着页面向下滚动，经历亏凸月、下弦月，滑到底部时正好化为一弯残月。
