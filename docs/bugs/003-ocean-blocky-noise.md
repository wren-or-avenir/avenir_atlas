# 003 海面几何块状与像素方块（噪声不连续）

- 发现日期：2026-09-05
- 严重程度：中（视觉粗糙，非功能故障）
- 状态：已修复，待视觉验收

## 复现步骤

- 海面浪形出现约 1/6 屏大的几何块，块间相位突变，像"几何拼接"
- 浪花呈矩形分段，段边界硬直
- 夜晚荧光闪点呈方形像素块

## 定位分析

- vert：相位噪声取 `hash(floor(position.xy * 6.0))` 格点值，格间相位硬跳变
- frag：浪花条纹用 `hash(vec2(0.0, floor(aligned.y * 5.0)))` 分段相位，段间不连续
- frag：闪点"整格点亮"；且用了反向 `smoothstep(0.5, 0.05, ...)`，
  GLSL 规定 edge0 ≥ edge1 时结果未定义

## 修复记录

- 两个着色器统一引入 `valueNoise`（双线性插值 hash），替换全部格点噪声
- 闪点改圆形软边 `1.0 - smoothstep(0.05, 0.5, length(cellPos))`，
  网格 160 → 180 加密，触发阈值 0.9 → 0.92
