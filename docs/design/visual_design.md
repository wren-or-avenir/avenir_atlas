# 暂定设计
## 背景
- 当前海洋需求见 [ocean.md](ocean.md)，逐图分析、着色器方案与验收见 [ocean-rebuild.md](ocean-rebuild.md)。本轮按第 8–9 节反馈联动浅水减速、破碎门槛、非对称浪面和残沫消散，保留深浅渐变与海底透视；观感待用户验收。
- 高处俯视、上深下浅、无地平线和沙滩；白天浅水可见水下礁石，主参考为 day07 的浪花与 day11 的中浪。
- 夜间近黑海水，局部破浪/礁石扰动激发蓝眼泪，主参考为 night05 的小浪与 night11 的大浪；不做全屏随机浮游闪光。
- 先以自然变化的浪组实现大小浪节奏，本轮不实现天文引力与潮汐模型。

## 极端气候与真实映射
- 台风与暴雨： 页面中增加雷电和斜向雨滴特效，持续的雨滴，偶尔的雷电，整体页面饱和度降低，亮度略微下降。斜向倾角由天气参数驱动，不写死。
## 经纬2D地图菜单与 3D 地球联动
- 将导航菜单重构为真实的地区，设计金色线条轮廓的世界地图。南太平洋有一个金色的台风。
- 整个世界地图位于首页中部，占据页面二分之一的面积
- 鼠标未悬停的时候，第一级菜单对应的地区轮廓呼吸灯闪烁，有金色倒三角图标悬浮于地区正上方，并写出对应板块名字，呼吸灯效果。
- 点击一级目录的内容后，如果后面对应的还有二级目录，放大聚焦该板块，有金色倒三角图标悬浮于地区正上方，并写出对应板块名字，呼吸灯效果。
- 当鼠标悬浮在该坐标上时，角落的 3D 地球（左上角）自动自转并平滑聚焦到地区板块，2D世界地图菜单该板块由线条的轮廓变成实色的地区板块。

## 移动端适配与降级
- 触屏设备没有 hover，地图联动改为 tap 触发：板块实色、二级聚焦、3D 地球聚焦均由 tap 驱动。
- 移动端地图不占首屏 1/2，收缩为紧凑宽度，呼吸灯与金色倒三角保留。
- 移动端海洋背景退化为 CSS 静态渐变，3D 地球默认隐藏，避免 WebGL 性能开销。
- WebGL 不可用或上下文丢失时，组件一行 early-return 静默移除，页面退化为纯 CSS 呈现，禁止白屏。
